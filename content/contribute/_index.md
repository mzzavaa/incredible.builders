**Purpose.** The front door for contributors. It should take a capable engineer from "interested" to "first merged pull request" in one evening.

**Contains.**
- Contribution paths: code, docs, labs, teardowns, showcase review, translation
- First contribution walkthrough in five steps
- Standards summary: tests, docs, commit style, licence header
- Review expectations, including how fast we respond and what blocks a merge
- Recognition: how contributors are credited on project pages
- Where to ask questions before you write code

**Primary CTA.** Pick a good first issue and open a pull request.
