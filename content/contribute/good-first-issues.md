**Purpose.** Remove the hardest step, which is choosing what to work on. For newcomers who want a real task, not a typo fix.

**Contains.**
- Live list aggregated across the GitHub org by label
- Difficulty and estimated effort per issue, set by maintainers
- Grouping by skill: Python, TypeScript, Terraform, docs, design
- Claiming etiquette: how to signal you are working on something and how long you hold it
- Mentor column showing who will answer questions on each issue
- What to do if an issue turns out to be bigger than labelled

**Primary CTA.** Claim an issue in a comment and start.
