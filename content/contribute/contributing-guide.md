**Purpose.** The detailed rules of engagement. For a contributor who is ready to write code and wants to avoid a review round trip.

**Contains.**
- Local setup per language, with the version manager we assume
- Branch naming, commit message format, and pull request title convention
- Test requirements by change type, and what may skip tests
- Documentation requirement: no user-facing change merges without a docs update
- Review checklist a maintainer runs, published so you can pre-run it
- Signing, licence header, and developer certificate of origin
- Release process and how your change reaches a version

**Primary CTA.** Run the review checklist against your branch, then open the pull request.
