**Purpose.** Project page for the user group toolkit. For organisers who want event operations as code rather than a folder of spreadsheets.

**Contains.**
- Component list: site template, CFP intake, speaker profiles, stream overlays, recap generator
- Quickstart: fork, set five config values, deploy the site
- Automation map: what runs on merge, what runs on schedule
- Data model for events, speakers, and sponsors
- Adoption notes from groups already running it
- Explicit scope line: this repo is the tooling, community programme lives elsewhere

**Primary CTA.** Fork the template and deploy a group site.
