**Purpose.** Project page for the agent scaffold. For an engineer deciding whether to adopt it instead of writing orchestration glue again.

**Contains.**
- What it does in three sentences, plus what it deliberately does not do
- Quickstart: clone, configure, run the sample crew locally in under five minutes
- Architecture diagram: router, tool layer, trace sink, eval harness, budget guard
- Extension points: adding a tool, swapping the model provider, custom evaluators
- Cost note: default budget caps and what they mean per run
- Roadmap and current open issues, pulled from GitHub
- Related lab and teardown links

**Primary CTA.** Run the quickstart, then open an issue with what broke.
