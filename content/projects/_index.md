**Purpose.** The index of every open source project the Incredible builders community maintains. It exists so an engineer can judge maturity in ten seconds and clone in one minute.

**Contains.**
- Filter bar: status (active, stable, archived), language, cloud, category
- Card grid rendered from data/projects.yaml, one card per project
- Per card: name, one-line description, stack chips, stars, licence, last release
- "Looking for maintainers" row highlighting projects with open maintainer slots
- Short note on our support promise and what archived means

**Primary CTA.** Open a project page and run the quickstart.
