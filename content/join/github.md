**Purpose.** Orient a developer inside the GitHub org so they can find the right repo and the right issue quickly.

**Contains.**
- Org structure: project repos, template repos, and this site
- Naming and label conventions, including the labels our tooling depends on
- Issue and discussion templates, and when to use which
- Security reporting path for vulnerabilities, kept separate from public issues
- Access levels: triage, write, maintain, and how each is earned
- Automation running on the org and what it will do to your pull request

**Primary CTA.** Star the org and watch one repo you care about.
